## 📊 Project Overview

This project analyzes IPL data from 2008 to 2025 using Microsoft Power BI. It provides interactive dashboards to explore team performance, player statistics, and season-wise trends.

The objective is to transform historical IPL data into meaningful insights through data cleaning, analysis, and visualization.
